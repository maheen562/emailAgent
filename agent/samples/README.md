# Sample job-alert emails

Used by demo mode (`EMAIL_PROVIDER=demo`) and the tests. **All companies, jobs and
links are fictional.** The sender addresses mimic real job boards only so that
source detection can be tested.

They were chosen to exercise the scoring: good matches, senior roles, onsite jobs
in other cities, an unpaid internship, US night-shift hours, and a scam-like
posting that asks for a registration fee. They also cover HTML, plain-text and
multipart emails.
